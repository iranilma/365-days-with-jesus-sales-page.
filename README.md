# 365 Days With Jesus — High-Converting Sales Page

This repository contains the standalone, high-converting sales page for **365 Days With Jesus** ($17 Complete Digital Bundle).

## 🌸 Visual Identity & Brand System

- **Warm Ivory (`#FAF6F0`)**: Primary background canvas
- **Deep Plum (`#754057`)**: Headlines, primary CTA buttons, high-impact offer card
- **Warm Gold (`#C69A56`)**: $17 price pill, decorative accents, botanical sprigs
- **Soft Blush (`#F0D9D5`)**: Card highlights, badges, delicate borders
- **Warm Cocoa (`#55443F`)**: High-contrast, optical-grade readable body text
- **Soft Sage (`#A8B09B`)**: Spiritual growth accents & benefit checkmarks
- **Typography**: Cormorant Garamond (headlines) & Plus Jakarta Sans (body)

## 🚀 One-Click Vercel Deployment

1. Create a new repository on your GitHub account (e.g. `365-days-with-jesus-sales-page`).
2. Push this folder to your repository:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/365-days-with-jesus-sales-page.git
   git branch -M main
   git push -u origin main
   ```
3. Open [Vercel](https://vercel.com) and click **"Add New..."** -> **"Project"**.
4. Import the repository and click **Deploy**.
5. Connect your custom domain (e.g. `365dayswithjesus.com`).
